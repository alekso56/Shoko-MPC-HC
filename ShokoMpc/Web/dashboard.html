  1. Install MPC-HC if needed.

What gets installed?

A small shoko-mpc: link handler in your Windows user profile. It starts when a play link is opened and stays active to save playback position and watched status. It accepts links only from the server you configure, then starts your chosen MPC-HC executable. There is no installed Windows service or browser extension. The helper exits after syncing or closing the player.

The server plugin streams the original video with seeking support. Playback links are single-use and expire after 90 seconds; video sessions last 12 hours. Shoko API keys stay in Shoko's browser session.

If playback does not start

  • Use the Open MPC-HC link in the notification if your browser needs another click.
  • Re-run setup if the server address or MPC-HC location changes. The configured address must match the browser address exactly, including the port and any reverse-proxy prefix.
  • After restarting Shoko, click Play again to create a new video session.

Episodes are marked watched for the account that launched playback when the player reaches 90%. Seeking past 90% also counts; every part of a split episode must reach the threshold. Stopping earlier leaves it unwatched. Update both this plugin and Windows Setup, then refresh Shoko to see watched changes. Your position is saved in Shoko every five seconds and when you pause or close the player. Reopening resumes from that position. Reaching 90% clears the bookmark so finished episodes start from the beginning. Update Windows Setup to enable resume. Embedded subtitles work as part of the original file; separate subtitle files are not handed over.

To remove the Windows handler, run Uninstall.cmd from Windows Setup. Disable or uninstall this plugin in Shoko and restart Shoko to remove its episode buttons.
