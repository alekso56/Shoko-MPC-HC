SHOKO MPC-HC · 0.1.2

Your episodes, in MPC-HC.

Click ▶ MPC-HC beside an episode in your Shoko collection. MPC-HC starts on your Windows PC, even when closed.

Set up this Windows PC once

  1. Install MPC-HC if needed.
  2. Download and extract Windows Setup to a folder.
  3. Run Install.cmd. Set the Shoko server address below and select your MPC-HC executable. No administrator account is required.
  4. Refresh the Shoko episode page, then click ▶ MPC-HC. Allow the browser to open Shoko MPC-HC; if offered, remember the choice for this site.

What gets installed?

A small shoko-mpc: link handler in your Windows user profile. It runs only when a play link is opened. It accepts links only from the server you configure, then starts your chosen MPC-HC executable. There is no background service or browser extension.

The server plugin streams the original video with seeking support. Playback links are single-use and expire after 90 seconds; video sessions last 12 hours. Shoko API keys stay in Shoko's browser session.

If playback does not start

  • Use the Open MPC-HC link in the notification if your browser needs another click.
  • Re-run setup if the server address or MPC-HC location changes. The configured address must match the browser address exactly, including the port and any reverse-proxy prefix.
  • After restarting Shoko, click Play again to create a new video session.

Version 0.1 does not sync watched status or resume position. Embedded subtitles work as part of the original file; separate subtitle files are not handed over.

To remove the Windows handler, run Uninstall.cmd from Windows Setup. Disable or uninstall this plugin in Shoko and restart Shoko to remove its episode buttons.

Built for Shoko 6.0.0-dev.550 / Abstractions 6.0.0-alpha.112 and Web UI 2.6.0-dev.153. The UI adapter follows AniDB episode links and may need an update if Shoko changes its episode layout.
